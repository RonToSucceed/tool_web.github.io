座標轉換數學式與此工具使用相同的旋轉慣例 展開／收合
以下皆採右手座標系與主動旋轉。欄向量座標點 p 經旋轉後為 p′ = Rp；矩陣採 row-major 顯示。
01

旋轉矩陣作用於座標點

將原始座標乘上 3×3 rotation matrix

⌈ x′ ⌉
│ y′ │
⌊ z′ ⌋ = ⌈ r₀₀　r₀₁　r₀₂ ⌉
│ r₁₀　r₁₁　r₁₂ │
⌊ r₂₀　r₂₁　r₂₂ ⌋ ⌈ x ⌉
│ y │
⌊ z ⌋
x′ = r₀₀x + r₀₁y + r₀₂z　　y′ = r₁₀x + r₁₁y + r₁₂z　　z′ = r₂₀x + r₂₁y + r₂₂z
02

Quaternion → Matrix

q = (w, x, y, z)，且 ‖q‖ = 1

R = ⌈ 1−2(y²+z²)　 2(xy−wz)　 2(xz+wy) ⌉
│ 2(xy+wz)　 1−2(x²+z²)　 2(yz−wx) │
⌊ 2(xz−wy)　 2(yz+wx)　 1−2(x²+y²) ⌋
座標也可直接寫為純 Quaternion：p′ = q p q⁻¹
03

Euler → Quaternion

ZYX：Yaw(ψ) → Pitch(θ) → Roll(φ)

w = cφcθcψ + sφsθsψ
x = sφcθcψ − cφsθsψ
y = cφsθcψ + sφcθsψ
z = cφcθsψ − sφsθcψ
其中 cφ = cos(φ/2)、sφ = sin(φ/2)，θ、ψ 亦同。
04

Quaternion → Euler

輸出 Roll(φ)、Pitch(θ)、Yaw(ψ)

φ = atan2(2(wx+yz), 1−2(x²+y²))
θ = asin(clamp(2(wy−zx), −1, 1))
ψ = atan2(2(wz+xy), 1−2(y²+z²))
當 Pitch = ±90° 時會發生 gimbal lock，多組 Euler angles 可能代表同一旋轉。
05

Axis–Angle ↔ Quaternion

單位旋轉軸 û = (uₓ, uᵧ, u_z)，旋轉角 α

q = (cos(α/2), uₓsin(α/2), uᵧsin(α/2), u_zsin(α/2))

α = 2 acos(w)
û = (x, y, z) / √(1−w²)
輸入軸不必預先正規化；工具會先計算 û = u / ‖u‖。
